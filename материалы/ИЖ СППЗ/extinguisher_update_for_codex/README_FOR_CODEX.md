# README_FOR_CODEX

Этот пакет подготовлен как единый входной набор для доработки проекта ИЖ СППЗ по карточке огнетушителя.

## Порядок работы

1. Сначала обновить существующее ТЗ проекта ИЖ СППЗ с учетом новых требований:
   - выбор изготовителя;
   - выбор модели;
   - срок службы по паспорту в годах;
   - кнопка паспорта.
2. Затем внести изменения в программу в соответствии с обновленным ТЗ.
3. Существующую логику автоматического расчета сроков перезарядки не менять.
4. Использовать `fire_extinguisher_reference_v1.json` как стартовый справочник `изготовитель -> модель -> срок службы -> официальный паспорт`.
5. PDF-паспорта локально не хранить. Использовать только официальные ссылки производителей.
6. Если официальной ссылки на паспорт нет, кнопку паспорта не показывать.
7. После изменений обязательно проверить:
   - сохранение новой карточки;
   - редактирование карточки;
   - повторное открытие карточки после сохранения.

## Состав пакета

- `fire_extinguisher_reference_v1.json` - стартовый справочник по изготовителям, моделям, срокам службы и официальным ссылкам.
- `prompt_codex_extinguisher_database.txt` - подробное задание на изменение ТЗ и программы.
- `README_FOR_CODEX.md` - краткая инструкция по порядку выполнения работ.

## Важные ограничения

- Не хранить PDF внутри базы или локальных ресурсов приложения.
- Не показывать неофициальные ссылки на паспорта.
- Не зашивать сроки службы непосредственно в UI через набор `if/else`.
- Все автоподстановки выполнять из централизованного справочника.
