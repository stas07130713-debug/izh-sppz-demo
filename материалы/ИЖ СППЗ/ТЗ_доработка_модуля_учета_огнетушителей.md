# Техническое задание на доработку модуля учета и обслуживания огнетушителей

Версия требований: 21.08.2026.

## 1. Цель доработки

Доработать действующую программу учета огнетушителей так, чтобы она обеспечивала:

1. Ведение индивидуальной карточки каждого огнетушителя по ГОСТ Р 59641-2021 с изменением № 1.
2. Автоматическое формирование журнала эксплуатации систем противопожарной защиты без повторного ввода сведений из карточки.
3. Создание динамических чек-листов с учетом вида огнетушителя, ОТВ, конструкции, вида проверки и условий эксплуатации.
4. Автоматический расчет состояния огнетушителя по результатам чек-листа.
5. Групповое оформление проверки нескольких огнетушителей по одному мероприятию ТО и одному акту.
6. Учет работ собственной и сторонней лицензированной организации.
7. Хранение актов, протоколов, паспортов, фотографий и других подтверждающих документов.
8. Автоматический расчет следующих дат проверки, перезарядки, испытания и замены.
9. Полную историю изменений без физического удаления завершенных записей.

СП 9.13130.2009 утратил силу с 01.03.2025 и не должен использоваться программой как действующий нормативный документ. Ежеквартальную проверку реализовать как настраиваемый локальный эксплуатационный осмотр.

## 2. Основные сущности системы

Система должна содержать связанные сущности:

- карточка огнетушителя;
- объект, здание, этаж, помещение и точка установки;
- мероприятие проверки/ТО;
- чек-лист;
- группа огнетушителей по одному мероприятию ТО;
- запись журнала;
- организация-исполнитель;
- работник-исполнитель;
- акт, протокол, паспорт и фотография;
- дефект и корректирующее мероприятие;
- подменный огнетушитель;
- история изменения данных.

Карточка огнетушителя является основным источником постоянных сведений. Запись журнала является неизменяемым снимком данных на момент конкретного мероприятия.

**Вид огнетушителя:**

- водный — ОВ;
- воздушно-эмульсионный — ОВЭ;
- воздушно-пенный — ОВП;
- порошковый — ОП;
- углекислотный — ОУ;
- хладоновый — ОХ;
- специальный;
- другой.

При выборе «Специальный» или «Другой» обязательны описание и паспорт/техническая документация.

**Статус эксплуатации:** в эксплуатации; резервный; снят на ТО; в ремонте; временно заменен; выведен из эксплуатации; списан.

## 4. Автоматическое формирование журнала

При создании карточки и каждого мероприятия в журнал автоматически передаются:

- учетный номер;
- тип и марка;
- заводской номер и изготовитель;
- дата изготовления;
- объект, здание, этаж, помещение и место установки;
- вид ОТВ;
- номинальная масса или объем заряда;
- дата размещения;
- дата очередной проверки;
- дата очередной перезарядки;
- дата очередного испытания;
- срок службы;
- ответственное лицо, должность и организация.

При изменении места установки или ответственного лица создавать новую запись журнала. Старые записи не изменять.

## 5. Динамические поля по видам огнетушителей

### 5.1. Порошковый

Показывать поля: давление до и после проверки; положение стрелки; фактическая масса; факт вскрытия; марка порошка; состояние порошка; комки; сыпучесть; разрушение небольших комков; влажность; дисперсность; включение в выборку не менее 3%; результат выборочной проверки.

Пример: давление 1,55 МПа; стрелка в зеленом секторе; масса 6,62 кг; порошок Вексон-АВС 25; комков нет; параметры соответствуют.

Если порошок не соответствует хотя бы одному показателю, установить красный статус, создать требование перезарядки и предложить групповое мероприятие для огнетушителей той же марки.

### 5.2. Углекислотный

| Поле | Пример |
|---|---|
| Конструкционная масса | 7,20 кг |
| Первоначальная масса ОТВ | 5,00 кг |
| Нормативная полная масса | 12,20 кг |
| Фактическая масса при взвешивании | 12,08 кг |
| Фактическая масса ОТВ | 4,88 кг |
| Потеря массы | 0,12 кг |
| Потеря массы, % | 2,4% |
| Допустимая потеря | Не более 5% либо паспортное значение |
| Результат | Соответствует |
| Дата взвешивания | 12.03.2027 |
| Следующее взвешивание | 12.03.2028 |
| Состояние раструба | Исправен |
| Материал раструба | Диэлектрический |

Фактическую массу ОТВ, потерю массы и процент рассчитывать автоматически. При превышении допуска присваивать красный статус и требование перезарядки.

### 5.3. Хладоновый

Использовать контроль массы как для ОУ. Дополнительно хранить марку хладона, массу собранного остатка, способ обращения, документ передачи и организацию-получателя. Значение «Выпущен в атмосферу» запретить.

Пример: Хладон 227еа; остаток 3,8 кг; передан на регенерацию; акт № 18 от 12.03.2027; ООО «Экорегенерация».

### 5.4. Водный, воздушно-эмульсионный и воздушно-пенный

Показывать: номинальный и фактический объем; состав; концентрацию; срок хранения заряда; материал корпуса; внутреннее покрытие; признак стабилизированного многокомпонентного заряда; паспортную периодичность; способ обращения со слитым зарядом; документ передачи.

Пример: 6,0/5,95 л; концентрация 6%; корпус из нержавеющей стали; периодичность по паспорту 5 лет; заряд передан на утилизацию по акту № 19.

Для стабилизированного заряда, нержавеющего корпуса или специального внутреннего покрытия срок определять по паспорту.

## 6. Чек-листы

Для каждого пункта чек-листа предусмотреть:

- результат: «Соответствует», «Соответствует с замечанием», «Не соответствует», «Не проверено», «Не применяется»;
- критичность пункта: критический, значительный, незначительный;
- комментарий;
- фотографию;
- корректирующее мероприятие;
- ответственного и срок устранения;
- источник подтверждения: осмотр, измерение, акт, протокол.

### 6.1. Локальный ежеквартальный осмотр

Проверить место установки, доступ, видимость, знак, отсутствие препятствий эвакуации, кронштейн/подставку, корпус, коррозию, маркировку, пломбу, чеку, шланг/насадок/раструб, индикатор давления, сроки и температурные условия.

### 6.2. Ежегодная проверка

Включить локальный осмотр и дополнительно массу, давление, индикатор/манометр, утечку, источник вытесняющего газа, шланг, ходовую часть, крепление, срок службы корпуса, необходимость вскрытия, выборочную проверку порошка, взвешивание ОУ/ОХ и расчет следующей даты.

### 6.3. Полугодовая проверка

Основания: категория А; влажность более 90%; коррозионная среда; вибрация; температура близка к предельной; иные неблагоприятные условия. Основание обязательно сохранять.

### 6.4. Пятилетнее освидетельствование

Чек-лист должен включать разрядку, сбор ОТВ, очистку, наружный и внутренний осмотр, коррозию, уплотнения, ЗПУ, фильтры, редукторы, вентили, манометр, источник газа, шланг, резьбы, испытание, давление, результат, протокол, перезарядку, марку/количество ОТВ, пломбу, этикетку, паспорт и следующие даты.

Если корпус не выдержал испытание, установить статус «Неработоспособен — забракован», запретить перезарядку и создать операцию списания/замены.

### 6.5. Внеплановая проверка

Причина выбирается из списка: применение; частичное применение; нарушение пломбы; падение; повреждение; коррозия; отклонение давления; превышение утечки; истечение срока ОТВ; предписание; другое.

## 7. Автоматическое определение состояния и цветовая индикация

### 7.1. Проблема, которую необходимо устранить

Сейчас огнетушитель может оставаться в статусе «Исправен», даже если один или несколько пунктов чек-листа не пройдены. Это недопустимо. Итоговый статус должен вычисляться автоматически по наихудшему результату применимых пунктов.

### 7.2. Статусы

| Цвет | Статус | Условие | Последствие |
|---|---|---|---|
| Зеленый | Исправен | Все применимые пункты соответствуют | Эксплуатация разрешена |
| Желтый | Исправен с замечаниями — требует внимания | Есть незначительное/значительное замечание, не исключающее работоспособность | Создать мероприятие и срок устранения |
| Красный | Неисправен — эксплуатация запрещена | Есть критическое несоответствие либо отрицательный результат испытания | Снять с эксплуатации, заменить, направить на ТО/ремонт/перезарядку |
| Серый | Проверка не завершена | Есть «Не проверено» или отсутствуют обязательные данные | Нельзя завершить проверку |
| Синий | На ТО/в ремонте | Огнетушитель передан исполнителю | Требуется подменный огнетушитель |
| Черный/темно-серый | Забракован/списан | Корпус не прошел испытание или истек срок без возможности эксплуатации | Возврат в эксплуатацию запрещен |

### 7.3. Алгоритм

1. Исключить пункты со значением «Не применяется».
2. Если есть «Не проверено», итог — серый, завершение заблокировано.
3. Если есть критический пункт «Не соответствует», итог — красный.
4. Если отрицательный результат испытания корпуса, итог — «Забракован».
5. Если есть «Соответствует с замечанием» либо некритический пункт «Не соответствует», итог — желтый.
6. Зеленый допустим только при положительном результате всех применимых пунктов.
7. Ручное изменение красного/желтого статуса на зеленый запретить. Зеленый статус появляется только после устранения дефекта и повторной проверки.
8. Итог чек-листа немедленно обновляет цвет карточки, строки реестра, журнала и объекта на схеме.
9. При нескольких незакрытых проверках использовать наиболее тяжелый активный статус.

### 7.4. Критические несоответствия

По умолчанию считать критическими:

- давление или масса ОТВ вне допуска;
- превышение допустимой утечки;
- повреждение, трещина, вздутие или значительная коррозия корпуса;
- отрицательный результат испытания прочности/герметичности;
- неисправность ЗПУ, шланга или насадка, исключающая применение;
- отсутствие обязательного узла;
- несоответствие порошка;
- применение огнетушителя без последующей перезарядки;
- истечение срока службы;
- просроченная обязательная перезарядка/освидетельствование;
- иное условие, которое паспорт определяет как запрет эксплуатации.

Критичность шаблонов должна настраиваться администратором, но изменение сохранять в аудите.

## 8. Правила сохранения и завершения чек-листа

Чтобы не терять введенные данные, использовать фоновое автосохранение черновика. Основную кнопку назвать «Завершить проверку и записать в журнал».

Кнопка завершения должна быть неактивна, пока не выполнен один из вариантов.

### 8.1. Проверка собственными силами

Обязательно заполнены:

- фамилия, имя и отчество исполнителя;
- должность;
- организация;
- дата проверки;
- результаты всех применимых пунктов;
- комментарий и мероприятие для каждого замечания/несоответствия.

Пример: Иванов Иван Иванович; инженер по пожарной безопасности; ООО «Пример».

### 8.2. Сторонняя организация

Обязательно заполнены/загружены:

- наименование организации;
- ИНН;
- номер лицензии МЧС для соответствующих работ;
- дата выполнения;
- номер и дата акта;
- файл акта выполненных работ.

Ф.И.О. и должность исполнителя могут быть заполнены вручную либо подтверждены сведениями загруженного акта. Если в акте эти сведения отсутствуют, программа должна запросить их отдельно.

### 8.3. Сообщения валидации

Показывать конкретный список причин блокировки, например:

- «Не указана должность исполнителя»;
- «Не выбрана организация исполнителя»;
- «Не загружен акт сторонней организации»;
- «Пункт „Состояние корпуса“ не проверен»;
- «Для замечания не указан срок устранения»;
- «Не введена фактическая масса углекислотного огнетушителя».

Незавершенный черновик не должен изменять рабочий статус огнетушителя и не должен формировать окончательную запись журнала. Если в черновике выявлено критическое несоответствие, до завершения показывать предупреждение «Предварительно выявлена критическая неисправность».

## 9. Групповая проверка

Функцию назвать «Группа огнетушителей по одному мероприятию ТО», кнопку — «Групповая проверка». Не использовать отдельное слово «партия» без пояснения.

Окно выбора должно фильтровать огнетушители по объекту, зданию, этажу, помещению, виду, марке, ОТВ, статусу и срокам. Показывать флажок, номер, марку, заводской номер, место, ОТВ, статус и следующие даты.

Общие данные вводятся один раз: дата, мероприятие, организация, исполнитель, должность, лицензия, акт, протокол и общие замечания. Для каждого огнетушителя сохранять индивидуальный результат и отдельную запись журнала.

Для смешанной группы автоматически создавать разделы ОП, ОУ, ОХ, ОВ/ОВЭ/ОВП и передвижных огнетушителей. Разрешить общий результат, индивидуальные исключения, исключение единицы из акта и создание задания для неисправных единиц.

## 10. Подтверждение сторонней организацией

Добавить переключатель «Работы выполнены лицензированной сторонней организацией» и кнопку «Подтвердить выполнение по акту».

После подтверждения:

1. Отметить «Выполнено по акту» только у применимых операций.
2. Указать номер акта и файл как источник.
3. Не создавать вымышленные значения массы, давления, объема или испытательного давления.
4. Потребовать ручной ввод измерений либо подтвержденное извлечение из акта.
5. Создать запись журнала по каждому огнетушителю.
6. Пересчитать следующие даты.
7. Сохранить пользователя, дату и время подтверждения.

Перед массовым заполнением показать подтверждение: «Подтверждаю, что загруженный акт содержит сведения о выполнении всех применимых операций по выбранным огнетушителям».

## 11. Расчет сроков

Базовые интервалы ГОСТ: вода/вода с добавками и пена — 1 год; порошок, углекислота и хладон — 5 лет. Для стабилизированных водных/пенных зарядов, нержавеющего корпуса и специального покрытия применять паспорт изготовителя.

Алгоритм: получить срок паспорта; определить срок ГОСТ; проверить исключение; выбрать применимый более ранний срок; сохранить источник срока; ручную корректировку разрешать только с обоснованием и документом.

Формировать уведомления за 90, 30, 10 дней и в дату наступления срока.

## 12. Ограничения и запреты

Запретить:

- завершение без итогового результата;
- зеленый статус при замечании или несоответствии;
- завершение без данных исполнителя или акта;
- внешнее ТО без организации и лицензии;
- перезарядку без марки и количества ОТВ;
- смешивание порошков разных типов;
- преобразование одного типа огнетушителя в другой;
- перезарядку забракованного корпуса;
- удаление завершенной записи;
- изменение без истории и причины;
- выпуск хладона в атмосферу;
- снятие огнетушителя на ТО без фиксации подмены либо предупреждения об отсутствии подмены.

## 13. Отчеты

Реализовать карточку учета; журнал; перечень по зданиям; графики проверок, перезарядок и испытаний; истекающие сроки службы; снятые на ТО; отсутствие подмены; отсутствие паспорта/акта; групповую проверку; ведомость дефектов; реестр сторонних работ; реестр актов; историю изменений.

Экспорт: PDF, XLSX и печатная форма.

## 14. Аудит

Для каждого изменения хранить дату/время, пользователя, Ф.И.О., должность, организацию, старое и новое значение, основание и документ. Завершенные карточки и проверки физически не удалять; использовать архив и аннулирование с причиной.

## 15. Критерии приемки

1. Карточка содержит все десять полей формы ГОСТ.
2. Данные карточки автоматически переносятся в журнал.
3. Для мероприятия создается отдельная неизменяемая запись.
4. Чек-лист зависит от вида огнетушителя и проверки.
5. Для ОУ/ОХ рассчитываются масса ОТВ и потеря в процентах.
6. Для ОП учитываются давление и проверка порошка.
7. Для ОВ/ОВЭ/ОВП учитываются объем, состав и паспортная периодичность.
8. Реализованы локальная квартальная, годовая, полугодовая, пятилетняя и внеплановая проверки.
9. Итоговый статус всегда соответствует наихудшему результату чек-листа.
10. Замечание дает желтый статус; критическое несоответствие — красный.
11. Зеленый статус при непройденном пункте невозможен.
12. Кнопка завершения заблокирована без исполнителя либо полного комплекта сведений и акта сторонней организации.
13. Черновик автосохраняется без формирования итоговой записи журнала.
14. Подтверждение по акту не создает вымышленных измерений.
15. Групповая проверка создает отдельный результат для каждого огнетушителя.
16. Следующие сроки и уведомления рассчитываются автоматически.
17. Сохраняется полная история изменений.
18. Формируются печатные карточки, журнал, чек-листы и отчет группового мероприятия.

## 16. Тестовые сценарии

1. Все пункты пройдены — карточка зеленая, статус «Исправен».
2. Повреждена читаемость этикетки — желтый статус и задача на устранение.
3. Давление вне допуска — красный статус, эксплуатация запрещена.
4. Корпус не прошел испытание — «Забракован», перезарядка заблокирована.
5. Пункт не заполнен — серый статус, завершение заблокировано.
6. Не указана должность проверяющего — завершение заблокировано с понятной ошибкой.
7. Выбрана сторонняя организация без акта — завершение заблокировано.
8. Акт загружен, но отсутствует измеренная масса ОУ — завершение заблокировано до ввода/подтверждения значения.
9. В группе один огнетушитель неисправен — он красный, остальные получают собственные результаты.
10. После устранения дефекта и повторной проверки статус меняется на зеленый, старая красная запись остается в истории.
