# Сторонние компоненты и их лицензии

Требование пункта 23 ТЗ PlanVector Engine: ни один сторонний компонент не включается без лицензионного аудита и не должен создавать ограничений для будущего закрытого коммерческого продукта.

Проверять этот файл нужно при каждом добавлении зависимости.

## Правило отбора

Допускаются только **разрешительные** лицензии — MIT, Apache 2.0, BSD, ISC. Они позволяют распространять продукт в закрытом виде и продавать его.

**Запрещены** копилефт-лицензии — GPL, AGPL, LGPL со статической линковкой, SSPL — и любые лицензии с ограничением на коммерческое использование либо на количество пользователей.

### PlanVector Engine

Пакет `packages/planvector-engine` **не имеет ни одной зависимости**. Это сознательное условие: пункт 2 ТЗ требует возможности выделить ядро в самостоятельный продукт, а зависимости — первое, что этому мешает.

## Рассмотренные и не включённые

Пункт 23 ТЗ предписывает изучить родственные проекты как источник подходов. Изучение допустимо, заимствование кода — только после аудита.

| Проект | Лицензия | Решение |
|---|---|---|
| Potrace | GPL | **Не использовать код.** Копилефт несовместим с закрытым продуктом. Алгоритм трассировки контуров общеизвестен и может быть реализован самостоятельно |
| AutoTrace | GPL | То же |
| QCAD Community Edition | GPL | **Не использовать код.** Как источник представлений о структуре CAD-данных — допустимо |
| FloorplanTransformation | исследовательский код, лицензия требует проверки | Не включать до аудита. Требует нейросети, что противоречит принципу «сначала алгоритмика» из пункта 8 документа об архитектурной подложке |
| OpenCV.js | Apache 2.0 | Пригодна по лицензии. Пока не включена: для векторных PDF нужные сведения есть в самом документе точнее, чем в отрисованной картинке. Вернуться к вопросу на этапе обработки сканов |

## Формат PDF и DWG

DXF — открытый документированный формат, читается свободно.

**DWG не поддерживается намеренно.** Единственный практичный способ его чтения — библиотека Open Design Alliance, требующая платного членства. Это прямо запрещено требованием заказчика об отсутствии платы и претензий на использование.

## Как проверять

Перед выпуском версии:

1. `npm ls --all` — полное дерево зависимостей;
2. сверить лицензии всех новых пакетов с правилом отбора выше;
3. дополнить таблицы этого файла;
4. приложить тексты лицензий к дистрибутиву.
