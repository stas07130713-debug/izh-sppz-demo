# ADR-001. Выбор языка и платформы

Дата: 16.08.2026
Состояние: принято

## Задача

Выбрать язык и платформу для настольной программы, которая:

- работает полностью автономно на одном компьютере;
- в дальнейшем разворачивается на локальном сервере организации на 50–100 пользователей **без переписывания ядра**;
- много работает с чертежами: PDF, в перспективе DXF;
- должна поддаваться правке посторонним исполнителем — другим ИИ-инструментом или нанятым программистом.

## Рассмотренные варианты

**А. .NET 8 + C# + Avalonia.** Быстрые вычисления, строгая типизация, зрелая экосистема. Логика переносится на сервер ASP.NET как есть.

**Б. TypeScript + React + Electron.** Один язык для программы и для будущего сервера. Самый распространённый стек, лучше всего представленный в обучающих данных языковых моделей и на рынке труда. `pdf.js` — эталонная библиотека для PDF.

## Решение

Выбран вариант **Б: TypeScript + React + Electron**, база SQLite локально и PostgreSQL на сервере.

Изначально был выбран вариант А. Решение пересмотрено после того, как заказчик добавил требование о правке посторонними исполнителями. Это требование оказалось решающим: Avalonia слабо представлена в обучающих данных моделей, из-за чего сторонний ИИ систематически подставляет в её разметку конструкции из WPF, которые не работают. Программа, которую нельзя безопасно поручить постороннему, не отвечает поставленной задаче, какой бы правильной ни была её внутренняя архитектура.

## Последствия

Хорошие:

- один язык на весь проект: сценарии, интерфейс, настольная программа, будущий сервер;
- пакет с логикой переиспользуется сервером дословно, без переписывания;
- широкий выбор исполнителей и уверенная поддержка со стороны ИИ-инструментов;
- PDF обрабатывается самой известной и лучше всего документированной библиотекой.

Плохие, принятые сознательно:

- вычисления медленнее, чем на C#. Для этой задачи несущественно: узкое место — отрисовка, а она идёт через графическое ускорение;
- типизация слабее, чем в C#. Компенсируется строгим режимом TypeScript и запретом `any`;
- дистрибутив крупнее из-за Electron. Для промышленной настольной программы не имеет значения.

## Что осталось неизменным

Вся архитектура, описанная в проектной документации, действует дословно: ядро и сменные движки, порты инфраструктуры, транспортный шов, инварианты модели данных. Сменился только язык, на котором это записано.
