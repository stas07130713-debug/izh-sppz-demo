# ИЖ СППЗ

Интерактивный журнал систем противопожарной защиты. Настольная программа для российских предприятий: план здания и журнал эксплуатации оборудования — два представления одних и тех же данных.

Программа рассчитана на ведение журнала эксплуатации СПЗ, предъявляемого при проверке МЧС, поэтому у каждого назначенного срока есть ссылка на пункт нормативного документа, а история не удаляется никогда.

## Состояние

Шаг 1: **создание подложки плана**. Готово и работает.

- загрузка PDF, PNG, JPEG;
- для PDF — выбор страницы, разрешения и поворота, с расчётом размера подложки заранее;
- определение, векторный это чертёж или скан;
- задание масштаба по двум точкам или по масштабу чертежа;
- просмотр с приближением и перемещением;
- хранение подложек и исходных файлов на диске.

Дальше по плану: дерево объекта и конструктор типов, нанесение оборудования на план, движок регламентных сроков.

## Запуск

Нужен Node.js 20 или новее.

```
npm install
npm run dev
```

Собрать и запустить собранное:

```
npm run build
npm run preview --workspace @izh/desktop
```

Проверить себя:

```
npm run check
```

## Устройство

Программа собрана как ядро и сменные движки. Подробности — в [AGENTS.md](AGENTS.md), решения — в [docs/adr](docs/adr).

| Пакет | Назначение |
|---|---|
| `@izh/contracts` | Типы и интерфейсы. Единственное, что видят движки. |
| `@izh/core` | Сценарии работы. Не знает ни о хранилище, ни об интерфейсе. |
| `@izh/engine-plan-source` | Движок E1: PDF или картинка → подложка плана. |
| `@izh/desktop` | Окно программы, хранилище файлов, мост, интерфейс. |

## Где лежат данные пользователя

В папке приложения Electron, подкаталог `data`: изображения и исходные чертежи в `files`, сведения о подложках в `backdrops.json`. Точный путь показан в левом нижнем углу окна программы.

В данных нет абсолютных путей, поэтому папку можно скопировать на другой компьютер целиком.
